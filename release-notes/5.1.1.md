## 5.1.1 - 2026-10-13

A small fix on top of 5.1.0. Everything in the [5.1.0 notes](https://github.com/molitar/update-scanner-reborn/blob/main/release-notes/5.1.0.md) still applies.

### Fixed

- **Folder Settings now has the Autoscan interval**, like Global Settings. Links added to the folder start with that interval. Tick "Apply to all existing links" and "Apply Autoscan interval to existing links" to update the links already inside the folder.
